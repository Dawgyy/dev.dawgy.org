This site itself — a personal portfolio designed as a living index of my
work, writing and projects.

## Stack

- **React 19 + Vite 7 + TypeScript** for the application.
- **Tailwind CSS v4** with a custom dark-first design system.
- **Framer Motion** for page transitions and the word-by-word hero reveal.
- Content authored in **markdown** and loaded at build time.

## Notable details

- A cursor spotlight that lights card borders — the signature interaction.
- Open Graph share images generated at build time, one per route.
- A print-ready CV page derived from the same content.
- Per-route SEO, a generated sitemap, and accessibility passes
  (skip link, visible focus, reduced-motion support).

The full source is on [GitHub](https://github.com/Dawgyy/dev.dawgy.org).
