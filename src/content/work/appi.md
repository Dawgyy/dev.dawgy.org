APPI is a web-based document management system built for Arcelor Mittal.
It gives teams a controlled workflow for their documents — drafting,
validation, versioning and publication — with access scoped to the users
assigned to each document.

## My role

I work as a software developer on the application, contributing across
the React front-end and the .NET back-end, and on the SQL data layer and
Azure infrastructure that support them.

## Stack

- **Front-end** — React 19, MSAL React, JavaScript, HTML5, CSS3
- **Back-end** — .NET / .NET Core, ASP.NET Identity
- **Data** — SQL, T-SQL
- **Platform** — Azure DevOps, Azure AD
- **Tooling** — Git, Visual Studio Code
